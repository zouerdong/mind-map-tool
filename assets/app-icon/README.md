# Application icon

## Approved direction

The app icon uses the product owner's selected concept C: a central idea origin connected by six straight rays to differently sized idea points. The visual language is deliberately minimal and two-dimensional; it does not use a literal brain, head silhouette, curved network, text, or decorative star field.

The production master preserves the selected concept's dark indigo field, off-white origin, asymmetric six-ray structure, and blue/violet/pink color families. Production changes are limited to deterministic vector geometry, a macOS-safe rounded-square silhouette, and removal of raster shadows that lose clarity at small sizes.
