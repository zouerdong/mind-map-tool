### 1.4 连线与箭头（G-VIS 2026-09-06 定稿：双形态 + 全正交规整态）

**线形态语言（用户校准）**：散乱/自由态 = 平滑曲线；**整理后的规整态 = 全正交"电路线"折线**——除拐角圆弧外只允许横/纵方向线段，禁止斜线。两种形态在整理动画中连续过渡。

| token | 值 | 说明 |
| --- | --- | --- |
| 线宽 | 2px（次要线 1.5px） | 参考约 1.5–2 |
| 散乱态线型 | 实线贝塞尔（平滑曲线） | 自由放置/拖动时 |
| 规整态线型 | **正交折线**：水平出一小段（40px）→ 圆角垂直折 → 水平跨越 → 圆角垂直折 → 水平进入；拐点圆角 r≈12px（弧） | 相邻列走中缝转折；纵向模式轴对称转置 |
| 跨层长边（规整态） | 三级策略（G-VIS 2026-09-06 定稿，经用户三轮校准）：① **内部直连优先**——源锚高度到目标列之间无卡遮挡时，直接水平走到目标列前（全缝唯一转折 x）再垂直进入，不绕圈；② **被挡才绕贴边通道**——与图边界留 56px 的边缘通道（上/下按源就近），通道内多边按序偏移 14px；③ 垂直转折统一放目标列前 `tip.x - 24 - rank×spacing`（rank = 同缝按目标锚 y 升序），保证全缝唯一 | 路由的遮挡检测与通道分配由 VRA-040 实现并测试；原型证据：12/17 节点程序化检测零共线重叠、零穿卡 |
| 布线硬规则 | **整理后零共线重叠**：每条边独占水平走廊（= 目标锚 y，锚点按入边唯一分配）；垂直转折全缝唯一。拓扑必需的**交叉允许**（尽量少），重叠（共线并行重合）禁止 | 用户明确："线路绝不能重叠在一起"；VRA-040/080 以程序化检测验收 |
| 形态过渡 | 整理动画期间曲线→折线连续插值（同帧坐标），完成时为 fillet 折线 | VRA-040 路由 + VRA-060 动画共同约束 |
| 次线型 | 虚线 dash `5 4`；点线 dot `0.1 5` + round cap（两种形态下同语义） | D4：虚/实线为外观，均参与布局 |
| 箭头 | 实心三角，长 9、宽 7，同线色，指向目标卡边界（进入方向） | D4：默认有箭头 |
| 端点 gap | 4px（卡边界外留缝，稳定端点关系） | MOV 观察到留缝；取常量避免每帧吸附抖动 |
| 端口方向 | 横向布局（默认）：**右出左入**；纵向布局（可选）：底出顶入 | G-VIS：整理默认横向 |
| 多入边端口 | 目标进入边按入边序均分锚点（间距 ≥18px），源出边同理 | VRA-040 定精确分配规则 |

每态给「视觉呈现」与「必须可辨」；黑板为同构映射。原型按本表逐态呈现（见原型页状态切换器）。

| 状态 | 视觉呈现 | 必须可辨 |
| --- | --- | --- |
| 空白文档 | 全暖白底 + 底部居中一行克制提示「双击创建 · ⌥Space」；无常驻遮罩/模板墙/顶栏（ADR 0012 v1.1.0：提示仅 0 节点时显示，非交互、低对比可读、不遮挡输入） | 空白即邀请，不阻断 |
| 12 节点工作态 | reference-dag-12 构图：首行强调、下四层普通、双外弧、虚线、孤立顶右 | 层次/留白/汇聚关系一眼可读 |

| 多选 | 全部选中卡同描边；最后点击/焦点者附加角标记（4 角 6px 短线） | 主选与其余选中可区分，不靠颜色深浅 |
| 键盘焦点 | 焦点环 2px（offset 5px）+ 角标记；与选中并存时环在外、描边在内 | 焦点 ≠ 选中（形状双通道） |

| IME 组合 | 组合下划线 + 候选窗浮层；期间快捷键全部隔离 | 组合态不触发画布快捷键 |
| hover/连接候选 | hover 卡：边缘端口浮现（6px 圆点 `state.selection`）；连线拖拽：`edge.candidate` 预览线 + 目标卡端口放大 | 端口静止时弱化、可发现 |
| 连线中取消 | 拖回源卡或 Esc：预览线淡出（120ms，不动文档） | 取消不产生边不触发 dirty |
| 边选中·改线型 | 选中边加粗为 `state.selection` 3px；浮出线型工具条（实/虚/点线、反向、删除） | 线型为外观切换（D4），随文档持久化、可 undo |
| 文件菜单 | macOS 原生「文件」菜单：新建/打开/保存/存储为（OFR-2026-09-15：另存为与导出合并为单一面板，五格式分组；ADR 0012：命令承载在系统菜单，WebView 无顶栏） | 全键盘可达（⌘O 系列见快捷键表） |

| 恢复提示 | 同横幅样式：「上次未保存的更改可恢复」+ [恢复] [丢弃] | 不隐藏入口 |
| dirty close | 系统样式模态三分支：保存/放弃/取消 + 文档名 | 焦点围栏在模态内；Esc=取消 |
| 首次引导 | 首次启动 3 步锚点提示（双击建点→连线→整理），右下「跳过」 | 不污染文档；重放入口在偏好 |
| 主题切换 | 系统菜单「视图」切换暖白/黑板（ADR 0012），文档不 dirty（主题已是文档状态，切换=样式命令可撤销） | 两主题全部状态可辨 |

## 3. 可访问性底线（沿用 brief §6）

- 正文文本对比 ≥4.5:1（表内实算值满足）；眉题为辅助文字，弱于正文但 ≥3:1 或提供明度辅助；
- 图形/焦点/选中 ≥3:1；**不靠颜色单独区分**选中/焦点/主选（角标记 + 环形状）；
- 键盘全流程可达（AC-17 已实现，本表视觉焦点样式为其呈现层）；
- reduced-motion：动效契约全链路归零（见 motion contract）。

## 4. 极简 App Shell 提案（VRA-070 实施依据）

> **2026-09-13 状态说明**：本节 40px 常驻顶栏方案已被 ADR 0012（零 WebView chrome，命令迁 macOS 原生菜单）取代；ADR 0012 v1.1.0（DFR-030，from-user 2026-09-13）在此基础上批准两个状态化轻量元素——空白画布底部创建提示（0 节点）、右上浮动「整理 ⇧⌘L」按钮（≥2 节点、与系统菜单同 dispatcher）——并将上下文工具条定位为「主选节点附近、夹紧视口」。本节其余视觉参数（壳色、提示浮层样式）仍为实施依据。

```
┌──────────────────────────────────────────────────────┐
│ [文件 ▾]  未命名思维图 · 已保存     [整理 ⌘⇧L] [☰视图] [◐] │ ← 顶栏 40px，壳色 = canvas 微暗一档
├──────────────────────────────────────────────────────┤
│                                                      │
│                    画布（绝对主角）                     │
│                                                      │
└──────────────────────────────────────────────────────┘
```

- 顶栏 40px 常驻，仅左（文件菜单）/中（文档名+保存状态）/右（整理、视图入口、主题）；
- 节点样式与文字操作不进顶栏——进入选中态的**上下文工具条**（浮于选中卡上方 8px：角色、字体、字号、粗体、下划线、形状、框线、删除）；
- 常规成功提示：右下短浮层（2.5s 自动消失，**不改变画布布局**）；错误/冲突/恢复：顶栏持续横幅（不自动消失）；
- 默认空白文档不载入演示 fixture（VRA-070 验收条款）。

## 5. D1–D6 决策包（G-VIS 2026-09-06 全部经用户确认）

用户已选定参考方向（JPG 视觉 + MOV 运动），本包只校准实现语义，**不重开风格选择**。**校准结果（2026-09-06 用户逐项确认）**：D1（含黑板提案值）、D3、D4、D2/D5/D6 全部采纳；另确认两项新增决策：**D7 整理方向默认横向、可选纵向（随文档记忆）**；**D8 线形态语言：散乱态平滑曲线 ↔ 规整态全正交圆角折线（"电路线"），整理动画中连续过渡**（§1.4）。PRD 措辞更新（AC-15"垂直树"→"默认横向分层布局、可选纵向"、§5 主题/形态行按 D1）走 PRD 增补流程，由 VRA-020 承接。

### 5.1 旧文档视觉保留与文件兼容方向（G-SCHEMA 细化的输入）

- **方向 A（推荐）**：schema 新增可选「视觉 profile/字段」（角色、线型、眉题、暖白主题映射）；新写文档默认新视觉；**v1 旧文件读取时按显式映射表呈现新视觉，但不改坐标、不改权威 size、不重排**；保存时写新版本号，旧字段语义保留。
- 不做静默批量迁移（指南：任何批量迁移另需用户批准）；旧文档重开外观变化属于"主题 token 全局升级"的结果，必须在 release note/引导中可感知。
- 精确字段、canonical 顺序、脏标记影响由 VRA-020 的 Proposed ADR 定，本文件不预定义 schema。
