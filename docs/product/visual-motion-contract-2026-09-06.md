# 整理动效契约（散乱 → 规整）

日期：2026-09-06。状态：**G-VIS 已确认（2026-09-06 用户观看现场演示后采纳 800ms 方案）**；线形态双轨过渡（散乱曲线↔规整正交折线）与打断/undo 接续语义同批确认。由 VRA-060 实现于生产 RF 画布（实现前须 G-PLAN）。上位文档：[visual-target-brief](./visual-target-brief-2026-09-06.md) §4（运动观察）、[视觉 token](./visual-state-tokens-2026-09-06.md)（连线双形态与方向策略）。MOV 提供**节奏与观感**，不提供参数真值——下表数值经原型演示与用户确认，冻结为 VRA-060 的时间线常量。

## 1. 时间线（普通规模 ≤30 节点）

| 参数 | 值 | 说明 |
| --- | --- | --- |
| 总时长 `duration` | **800ms**（允许 700–900 校准区间） | MOV 主要变化约 800ms（motion-analysis 时间轴） |
| 节点主运动 | 600ms | 其余 200ms 为收束余量（主干归位） |
| easing | `cubic-bezier(0.22, 0.61, 0.36, 1)`（ease-out-cubic 族） | 柔和减速；**无弹跳、无惯性漂移、无回弹**（MOV 无） |
| 同层错峰 `per-node-delay` | 20–30ms/节点 | MOV 叶子陆续启动（2.80–3.40s 逐个右移） |
| 总错峰上限 | ≤120ms | 复杂图不随时长线性膨胀 |
| 错峰顺序 | **叶子先动，主干/汇聚最后归位** | MOV 3.40–3.65s 根与汇聚节点最后对齐 |
| 启动预备 | 无绿色脉冲等预备强调（参考的绿色高亮不采用） | 触发即开始；颜色系统只有橙一个强调（token §1.1） |

## 2. 每帧一致性（硬约束，VRA-060 验收）

1. **一个协调者、一个 rAF 时钟**：由 motion coordinator 每帧产出显示坐标集；节点、边、箭头、端口、控制点全部消费同一份。
2. canonical 终态在动画开始前以**一条 `MoveNodes`** 提交（可撤销、触发 dirty）；每帧只改显示坐标，**禁止每帧 commit**；持久化保存的是终态。
3. **线形态双轨过渡（G-VIS 2026-09-06 用户确认）**：散乱态为平滑曲线，规整态为全正交圆角折线（"电路线"，见 tokens §1.4）；整理动画期间按同一进度对两种形态的路径采样点连续插值（形态参数 m 随主运动 0→1），完成帧为显式圆角折线；undo 反向 m→0；打断冻结当前 m。禁止任何一帧曲线↔折线突变。
4. 边路径从当帧两端卡片 bounds 派生（默认横向：右出左入 + 端点 gap 4px；纵向可选：底出顶入）；**路由拓扑（锚点序、外绕通道上/下侧）在动作开始时冻结**——同一次动作内不重选路径（禁止线条瞬跳）。
5. 端口侧、通道分配同样冻结：锚点序号在动作内不变，位置随当帧卡片 bounds 移动。
6. 节点从某卡左侧移到右侧等换位场景：路径连续过渡（VRA-040 提供连续插值方案），仅"端点 ≤1px"不构成中段无跳形证明。
7. 拖动等普通交互**不套用**本过渡（过渡仅限整理动作生命周期；替换现实现"所有 documentVersion 变化都 transition"的做法——audit 差距 #4/#5）。

## 3. 视口

- 整理前后内容边界**并集 + 80px 安全边距**，一次性协调（平移为主，必要时缩放），**禁止每帧 fitView**；
- 终态在安全边距内则保持当前视口不动；
- 不把单个节点放大至 maxZoom；用户中途 pan/zoom 即交还视口控制（动画继续但镜头不再改）。

## 4. 打断与重入（状态机）

| 事件 | 行为 |
| --- | --- |
| 动画中重复整理 | 新计算为 no-op（终态已提交）→ 仅继续当前动画，不叠加历史 |
| 动画中再次整理（文档又变乱，如 undo 后） | 从**当前显示位置**接续到新终态，重置时钟，不跳终态 |
| 动画中拖动节点 | 立即终止该节点过渡，节点交给拖动；其余节点继续；该节点边跟随拖动坐标 |
| 动画中 undo/redo | 从当前显示位置 lerp 到对应历史态 |
| 动画中编辑/IME | 动画继续（不与文本输入互斥）；未提交文本不受影响 |
| 动画中保存/导出 | 使用已提交 canonical 终态（不是中间帧） |
| 文档切换/卸载 | 取消全部计时器；禁止旧 timer 写新会话 |
| 完成后 | 显示坐标=终态坐标，清理过渡状态 |

## 5. reduced-motion

`prefers-reduced-motion: reduce`：无位置/镜头/强调动画，**直接呈现终态**（终态仍是一条 `MoveNodes` 历史，一次 undo 可回）。不用渐隐/缩放冒充关闭位移动画。

## 6. 规模降级

- 300/450：取消错峰（总时长=主运动 600ms）、简化长边路由插值；帧预算仍按 P95≤32ms 门槛实测，**不隐藏节点/边取巧**；
- 大规模若仍超帧预算：在原型确认的视觉降级（如线宽不变但去箭头插值）逐级应用，任何降级都在 VRA-060 记录并复测。

## 7. 原型验收取样（G-VIS 材料）

- 夹具：`reference-dag-12-scattered`（12 节点/13 边）与 `motion-tree-17`（17 节点）；
- 关键帧：整理前 500ms、0/25/50/75/100%、稳定后 500ms（共 7 采样点）；
- 端点跟随：任取 3 条边，比较 50% 帧的线端点与两端卡片当帧 bounds 的 gap = 4px ±1 CSS px（固定视口）；
- 17 节点夹具观察：15 叶错峰 ≤120ms、根最后归位、叶子列等距收束；
- 打断演示：50% 处拖动一节点 → 无跳线；undo → 一次恢复全部旧坐标；
- 录像标注：浏览器隔离原型（非生产 RF）、macOS、100% 缩放、reduced-motion 两态。

## 8. 与生产实现的边界

本契约由 VRA-010 的隔离原型（自包含 HTML，数据=合成夹具）先行验证视觉方向；生产实现（VRA-060 接入 RF）须复用同一组常量与状态机定义，并以真实 RF 录像重新取证（VRA-080）。原型通过 ≠ 产品通过。
