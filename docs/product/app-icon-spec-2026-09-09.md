# Mind Map 应用图标规格

日期：2026-09-09  
状态：`SELECTED / VECTOR_MASTER_READY / INTEGRATION_PENDING`

## 产品意图

图标表达“一个 idea 的原点可以连接并启发 anything”。它必须与产品的底层体验一致：简单、随时可用、没有多余界面负担。

## 视觉定义

- 一块干净的深靛蓝底；macOS 交付物使用圆角方形轮廓与透明四角。
- 中央只有一个暖白色原点。
- 从原点向六个不同方向发出**直线**，不得改为曲线、脑沟或有机触手。
- 每条线末端有圆形 idea 点；大小有层级但不表达固定流程或树形父子关系。
- 三组颜色为蓝、紫、粉；允许线性渐变，不使用彩虹全色域。
- 视觉保持扁平矢量感；不得增加实体材质、3D 高光、厚重投影、人物侧脸、文字、字母或复杂星空装饰。

## 固定母版

权威可编辑源为 [`assets/app-icon/source/mind-map-app-icon.svg`](../../assets/app-icon/source/mind-map-app-icon.svg)，画布 `1024 × 1024`。选定概念 C 的结构与配色已经固化；集成阶段只能做格式导出和平台适配，不得重新设计几何、颜色或节点数量。

关键几何约束：

- 六条射线，全部为圆端直线；
- 一个中心圆点，六个末端圆点；
- 图形最外侧内容保持在圆角底的安全区内；
- 16px 尺寸仍能读出“中心点 + 放射连接”，不要求保留微弱背景渐变层次。

## 尺寸验收

必须检查 `16 / 32 / 64 / 128 / 256 / 512 / 1024px` 七档：

1. 透明四角正确，无白边、黑边或背景泄漏；
2. 中心点与六条射线没有被裁切；
3. 16px、32px 下射线仍然是直线且没有黏成一团；
4. 128px 以上可区分蓝、紫、粉三组颜色；
5. 不得对小尺寸单独移动节点或改变比例，所有尺寸必须来自同一母版；
6. Finder、Dock、应用切换器和 DMG 中不得继续显示旧的纯蓝占位图标。

## 变更边界

任何结构、颜色家族、节点数量或图标含义的变化都必须回到产品负责人重新选定；PNG/ICNS 导出参数、文件名和 Tauri 配置属于 PRR-068 集成范围。
