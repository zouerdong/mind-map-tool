# ADR 0020：层级深度调色板（depth tint ladder）

- Status: Accepted
- ADR-Version: 1.0.0
- Date: 2026-09-18
- Deciders: 项目负责人（2026-09-18 内测反馈批次定稿：阶梯「橙—黑—偏深黑灰—偏浅灰」，四级之后同四级；深色主题阶梯镜像）/ 主会话（工程实现）
- 任务来源: 2026-09-18 内测反馈：一级（出发点）橙色之外，二级与更深层级全是黑色，无法区分层级。

## Context

节点卡色此前只有两种角色：普通（近黑 `#141412`）与强调（橙 `#D97757`），属 G-VIS 冻结
调色板（ADR 0010；UI theme-tokens 与 export visual-style 同源）。规格原文明写节点
「不按行/入度/根自动变色」——本 ADR 是对该条款的修订，已获负责人口径。深度信息不在
schema 中，需要派生规则。

## Decision

1. **卡色 = 角色 × 深度阶梯**：`emphasis: true` 恒为橙卡（不变）；普通节点按深度着色——
   深度 1–2 → 黑（现状 `cardNormal*`），深度 3 → 深暖灰，深度 ≥4 → **镜像描边卡**
   （暖白主题 = 白卡黑边墨字；黑板主题 = 黑卡白边浅字）。
   阶梯语义「层级越深、视觉越退后」。
2. **深度定义（投影/渲染层派生，不落 schema，零迁移）**：以缩点 DAG 入度 0 节点为源，
   沿边方向 BFS 最短路径深度（源 = 1）；环内节点取其 SCC 最小深度；平局按文档序裁决，
   确定性规则与 organize 同风格。**完全无连线的孤立节点无层级语义，保持现状黑卡不染色。**
3. **手动「强调」语义不变**：任何深度的节点都可手动标橙；橙色不再等于层级 1
   （用户手动在深层标橙时两语义脱钩，以强调为准）。
4. **色值（两轮原型定稿，2026-09-18 负责人过目两轮）**：每主题新增 depth3 / depth4 两组
   token（fill/text/kicker，depth 1–2 复用现有 `cardNormal*`）+ depth4 描边 token
   （`cardDepth4Stroke`）。定稿值：浅色 depth3 `#57524B`（浅字）/ depth4 `#FFFFFF` 卡 +
   `#141412` 描边；深色 depth3 `#B4AEA0`（墨字）/ depth4 `#141412` 卡 + `#EFEAE0` 描边。
   第一轮阶梯间距被判定过近（1.58/2.08），第二轮拉大（2.37/7.78）；黑色主题四级
   「黑卡白边」为负责人从三变体原型中选定（B 变体），暖白四级加黑边形成镜像。
   语义契约以本 ADR 为准，后续色号微调在 token 层完成。

## Consequences

### Positive

- 二/三/四级一眼可辨，直接回应内测主诉；明度阶梯对色弱用户天然可辨（非色相通道）。

### Negative

- 连线编辑会实时改变下游深度 → 卡色即时跳变（判定为可接受的语义反馈，不做过渡动画）；
- `framesVisible=false`（隐藏框线）模式不受阶梯影响，层级在无边框模式下不可辨——记录为已知取舍；
- **depth≥4 引入描边卡**，是 G-VIS「无描边实心卡」语言的首次例外——经负责人两轮原型
  定稿确认为层级标记的刻意设计；导出 SVG/PDF 的 frame 描边支持随之落地（此前恒 null）；
- 导出 golden 全部涉卡色用例按 REGEN 重基线；相邻灰阶可感知度已在原型阶段验证。

## Validation

- 深度派生纯函数单元测试：BFS 最短路径、SCC 环降级、孤立节点不染色、确定性；
- 双主题 token 对比度检查（文字/卡底）；导出 golden 重基线后 `pnpm quality` 全绿；
- 视觉原型截图经负责人确认色值（深浅两主题各一）。
