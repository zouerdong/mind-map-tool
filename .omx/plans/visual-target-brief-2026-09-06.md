图片用作视觉主参考；视频用作运动主参考。图片是上→下的多源关系图，视频终态是左→右的树；默认仍按已批的纵向整理，借用视频的运动节奏。横向整理如要成为可选功能，需另作范围决定，不能凭视频自动加入。

原件由项目负责人提供，只在本地作设计参考；来源/再分发许可未核实，不把水印、文案或整张参考打包进产品。合成夹具保留几何与拓扑特征，使用本项目自写内容。

## 2. 从参考量取的视觉基线

颜色是 JPEG 内部平坦区域采样值；尺寸为原图近似读数，不是获批设计系统。VRA-010 需在 100% 缩放、固定画布中校准。

| 项目 | 参考观察 | 推荐起点 |
| --- | --- | --- |
| 画布 | 平坦暖白，近 `#F9F8F4` | 暖白，无纹理、无常驻点阵；与旧纯白条款的覆盖在规格中显式登记 |
| 普通卡片 | 近 `#141412` 实心，无明显投影/描边 | 普通节点深色填充，正文暖白；不使用渐变、玻璃或拟物 |
| 强调卡片 | 近 `#DA7757`，接近原批准 `#D97757` | 先以 `#D97757` 作产品 token，参考误差允许在校准时微调；卡片上用深色字 |
| 卡片尺寸 | 常见约 189×68，部分宽约 230 | 基准宽约 190、最小高约 68；长中文、多行可增大，不强制所有内容塞进同一小框 |
| 圆角/内距 | 圆角约 10–12；左右约 16，上下约 12–16 | 使用同一排版契约计算真实 size，UI 与导出共用 |
| 文字 | 上方约 10–11 的淡色眉题；正文约 15–16；英文有等宽观感 | 中文正文继续使用已批 Noto Sans SC；暂不新增字体包。眉题可选；短正文不强制变成两行 |
| 同层与层间 | 顶排间距约 16，后续并非等宽均匀铺满；行顶约 54/230/405/581/756 | 参考夹具先以 100% 下同层 gap 32–48、层间净空 88–112 校准；长内容可扩大，不把截图坐标硬编码为算法 |
| 关系线 | 深灰约 1.5–2 px 曲线、实心小箭头；次要关系用灰色点/虚线；有跨层外弧 | 从卡片边界出入，多边可分配端口；线在节点下层，外弧计入导出边界 |
| 编辑状态 | 静态参考未给出 | 橙色焦点/选中反馈；hover、focus、连线时出现端口；静止时弱化，保留可发现性 |

不能为仿参考新增英文专用字体后默默接受中文回退；如 VRA-010 证明现有字体无法达成目标，先记录体积、许可、导出嵌字成本和替代，再提出 ADR。

## 3. 最小产品语义建议（G-VIS 一次收口）

| 编号 | 推荐方案 | 与旧基线的关系 |
| --- | --- | --- |
| D1 | 新建文档默认采用暖白/实心卡视觉；黑板保留，同构的深底与可辨卡片边界 | 新参考覆盖原纯白、描边默认的审美方向；暗色的精确配色需展示后确定；旧文档不得静默重排或改变权威 size |
| D2 | 普通/强调两种节点色彩角色，由用户设置并持久化；默认普通 | 不按入度或“根节点”自动变色，整理不改变用户强调意图 |
| D3 | 可选的单行眉题 + 原有正文；眉题可为空，不设分类下拉，不解析 PLAN/BUILD | 新的编辑与持久化语义，须与 runs/撤销/测量一并设计；若用户只要单层文本，可在 Gate 精简，但应展示与参考差异 |
| D4 | 连线方向由现有 source→target 表达，默认有箭头；提供实线/虚线两种外观 | 路径由几何派生，线样式需保存。虚线默认只改变外观，仍参与布局；“参考线不参与层级”属于额外语义，不自动加入 |
| D5 | 不引入左侧层号、顶部文章标题、固定阶段分类、模板库 | 它们是参考图的编辑编排，非本工具已请求功能 |
| D6 | 用户主动整理，平时自由放置/连线；允许多个上游、跨层关系、环、孤立节点 | “规整”不把文档转成单父树；不增删边，不修改文本/样式 |

本轮只产规划；不修改 schema、不迁移文件。G-VIS 确认上述方案及高保真状态后，由 VRA-020 决定可读旧版、新写版本、缺省字段与 canonical 规则。兼容性不能用“尚未发布”跳过：本地已有用户文件也要保护。新旧版本的视觉保留策略必须明确，不自动批量重写旧文件。

## 4. 运动观察与可测试提案

### 4.1 视频观察时间轴

| 时间 | 可见行为 |
| --- | --- |
| 0.00–约 1.1s | 原杂乱图、短暂模糊/文字过渡；属于参考视频包装，不照搬 |
| 约 1.1–2.65s | 散布节点出现，根/汇聚节点建立，关系逐步显现 |
| 约 2.65–2.80s | 绿色轮廓强调，形成动作预备 |
| 约 2.80–3.40s | 叶子节点陆续移动到右侧同列，连线逐渐展开 |
| 约 3.40–3.65s | 根和汇聚节点左移、水平对齐，终态稳定 |
| 约 3.65–5.10s | 图形保持稳定，后续局部强调，与整理本身分开 |

以上为 60fps 源视频的抽帧观察区间，非精确触发测量。没有可辨认点击/拖拽，不能反推其交互实现。原视频端点存在间隙；本产品应有稳定的边界端点关系。

### 4.2 产品整理时间线（待原型校准）

推荐普通规模整段约 **700–900ms，起点 800ms**。节点主运动约 600ms，同层错峰 20–30ms、总错峰不超过 120ms；柔和减速，无弹跳、无惯性漂走。该数值是提案，不能称为从视频测得的参数。

1. 用户触发整理：先完成合法文本提交，或在 IME 组合期间暂不触发；使用不可变当前文档计算终态，计算期间不清空画布。
2. 计算成功：提交一条 `MoveNodes`，立即确立可保存/可撤销的终态；节点、线、箭头每帧消费同一组显示坐标与进度，视觉中间态不进入文档。端口侧、路由通道与控制点也要连续，不能每帧重新离散选路造成跳形。计算超出坐标/资源上限时明确失败，文档/历史不变，不显示整理成功。
3. 视口：不从当前视野突然跳到原点。终态在安全边距内则保持镜头；超出时对前后边界并集做一次受控平移/缩放，不能每帧调用自动 fit。普通建点和文字输入仍不主动缩放。
4. 中途 undo/redo：从当前显示位置接续到相应历史终态；重复整理不叠加历史；拖动开始时先终止视觉过渡并以可预测的当前目标接管，不能留下分离的边。精确打断策略由 VRA-010 原型定稿。
5. 保存/导出使用已提交的 canonical 终态，短暂显示“整理目标已保存/导出”或等待视觉到达再反馈，不能导出半路坐标。
6. `prefers-reduced-motion`：无位置/镜头/强调动画，直接到终态且仍是一条历史。长图与 300/450 场景取消错峰或降低绘制成本，不能靠隐藏节点/边得到性能绿灯。

## 5. 完整状态矩阵

参考只是内容区，下面是产品补齐要求；VRA-010 给出同一方向的全部状态，不另做三种无关风格。

| 状态 | 必须可见/可做 | 验收重点 |
| --- | --- | --- |
| 空白暖白/黑板 | 空白画布，克制的创建提示和文件/整理入口 | 不出现首页/模板墙，非强制引导 |
| 12 节点工作态 | 普通/强调、眉题/正文、汇聚/长边 | 对齐静态参考的节奏、层次与留白 |
| 创建/编辑/IME | 光标、正确正文颜色、可选眉题、中文组合 | 创建直接输入；编辑/提交不跳字号、不丢 runs |
| 单选/多选/键盘焦点 | 选择与焦点可区分，上下文工具 | 正文编辑与画布快捷键隔离；不能只靠颜色 |
| 连线/改线样式 | 可发现端口、方向预览、取消路径 | 多入边、箭头、实虚线，边界端点稳定 |
| 整理/undo/redo | 连续变化且保持节点身份 | 中间帧同步、终态可继续编辑、一次历史 |
| 文件菜单/导出 | 新建、打开、保存、另存为、SVG/PNG/PDF | 操作入口可发现；三格式与画布一致 |
| 保存中/失败/冲突/恢复 | 简洁且可行动的反馈 | 不改变画布高度，不能隐藏恢复入口 |
| dirty close | 保存/放弃/取消与明确文档名 | 保持既有生命周期保护、焦点围栏 |
| 首次引导/重放 | 锚定真实动作的短提示 | 可跳过、不污染文档、无大面积常驻遮罩 |
| 小窗口/高 DPI | 800×600、1280×800，1×/2× | 无横向挤压工具条，文字/线清晰；尺寸为本批建议测试档 |

App Shell 推荐：单个文件菜单、明确的整理按钮、低干扰视图入口；节点样式与文字操作进入上下文工具；保存状态贴近标题，普通成功提示短暂浮层且不挤动画布。错误/冲突必须持续到处理，不复用会自动消失的成功提示。

## 6. 新的完成标准

- 同一合成内容同时给出参考构图、应用工作态、SVG、2x PNG、PDF；不是只展示空白首页。
- 静态检查拆为“固定参考坐标验证外观”与“算法生成终态验证规整”，不能硬编码坐标后声称算法达标。
- 录制整理前、0/25/50/75/100% 进度及稳定后帧；节点/边端点误差按固定视口目标 ≤1 CSS px，测量排除抗锯齿像素噪声。
- 正文对比 ≥4.5:1，必要图形/焦点 ≥3:1；小眉题不能照抄成难读灰字。颜色不足时用明度/边界辅助，并记录与参考的有意差异。
- 用户验收点集中为 G-VIS（第一组完整样式+动效原型）与 G-FINAL（真实 macOS 产品），中间工程卡由 Agent 相互审查。
