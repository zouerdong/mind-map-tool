# 快捷键表（键位专项讨论定稿 2026-08-29；单一事实源 `src/app/keyboard.ts`）

macOS 用 ⌘，Windows 移植用 Ctrl（同一归一化）。键位为数据不是逻辑：改键 =
改 `keyboard.ts` / `onKeyDown` 判定 + 本表 + 相关测试，机制不动；全局热键
另支持运行时换绑（存本机偏好，原生菜单 `设置/全局热键…`）。

## 命令承载（PRR-065 / ADR 0012）

生产（Tauri/macOS）命令由**原生应用菜单**承载：应用级快捷键同时是菜单
accelerator，按键被 macOS 菜单拦截产生唯一 menu event，经 host 定向发给
最近聚焦窗口的单一 dispatcher（`app-commands.ts`）——**WebView keydown
在生产环境不派发应用级快捷键**（exactly-once）。浏览器 dev（无原生菜单）
由 keydown 派发同一命令。多窗口命令始终定向最近聚焦窗口。

原生菜单专属 accelerator（无 WebView keydown 路径）：

| 快捷键 | 命令     | 说明                                                |
| ------ | -------- | --------------------------------------------------- |
| ⌘Q     | 退出     | host-owned：逐窗 fail-closed 关闭协议（MRT-003 X2） |
| ⇧⌘N    | 新建窗口 | host-owned：activation 语义（同 Dock/图标；D1）     |
| ⌘W     | 关闭窗口 | host-owned：最近聚焦窗口原生 close → 三分支协议     |

## 系统级（全局热键，任意前台应用下生效）

| 快捷键 | 动作     | 说明                                                                                                                                                     |
| ------ | -------- | -------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ⌥Space | 同键分流 | **未显示/最小化/失焦** → 唤醒画布（show + focus，不动文档）；**已聚焦** → 视口中心建新 idea 并自动进入编辑（「捕捉 idea」全局第一动作）[定稿 2026-08-29] |

> 唤醒语义含"可见但失焦"（被遮挡）：先聚焦，再按一次才建——不盲建。
> ⌥Space 机器实测空闲（Spotlight 占 ⌘Space、输入法占 ⌃Space，均不冲突）。

## 编辑（原生菜单 accelerator → dispatcher；OFR-2026-09-14 #5）

| 快捷键 | 动作 | 说明                                                                                                                                                                  |
| ------ | ---- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ⌘Z     | 撤销 | 生产：编辑菜单自定义项 accelerator 拦截 → 唯一 menu event → dispatcher（不再依赖画布焦点）；文本编辑中原生文本撤销，否则 session 文档撤销。浏览器 dev：画布层 keydown |
| ⌘⇧Z    | 重做 | 同上（session 文档重做；多节点位移由 MotionCoordinator reverseTo 平滑接续）                                                                                           |

## 画布级（焦点在画布、非编辑态）

| 快捷键           | 动作                   | 说明                                                                      |
| ---------------- | ---------------------- | ------------------------------------------------------------------------- |
| ⌘A               | 全选                   | 全部节点进入选择（Delete 删除）[MM-089]                                   |
| Delete/Backspace | 删除选择               | 节点 + 选中边（incident 边原子删除）                                      |
| 方向键 ↑↓←→      | 节点间导航             | 60° 方向锥最近节点；无焦点时从首个节点起 [MM-089]                         |
| ⌘+ / ⌘- / ⌘0     | 放大 / 缩小 / 适应内容 | 画布缩放（⌘= 同放大）[MM-089]                                             |
| ⌘L               | 键盘连线（发起）       | 焦点/选中为 source → 方向键换候选 → Enter 确认 / Esc 取消 [MM-089]        |
| Enter            | 进入编辑               | 焦点节点→编辑（建节点职责已移交 ⌥Space；无焦点时无动作）[定稿 2026-08-29] |
| Esc              | 取消连线               | 连线模式退出（编辑态 Esc 另承担取消编辑）                                 |

## 节点编辑框内（textarea）

| 快捷键 | 动作 | 说明                                                      |
| ------ | ---- | --------------------------------------------------------- |
| Enter  | 换行 | textarea 默认行为，多行创意卡片 [定稿 2026-08-29]         |
| ⌘Enter | 提交 | 收起编辑框，文本 + 权威 size 同命令提交 [定稿 2026-08-29] |
| Esc    | 取消 | 恢复原文本                                                |
| blur   | 提交 | 失焦即提交（一次）                                        |

## 隔离规则（PRD §6 / AC-02）

- 输入控件（textarea/input/contenteditable）内：应用级快捷键全部不派发（编辑自身处理 Enter/Escape）；
- IME 组合期间（isComposing / keyCode 229）：应用级与画布级快捷键均不派发；
- ⌘Z/⌘⇧Z 生产环境经编辑菜单 accelerator 到 dispatcher（编辑态分流原生文本撤销）；浏览器 dev 仍由画布层 keydown 处理；
- quick-create 信号在编辑/连线态被忽略（不打断进行中的工作）。
